# Подключение DeepSeek для физлица

Пошаговая инструкция для python-agent. Общие настройки описаны в [README](../README.md).

Что получится в конце: агент отправляет запросы прямо в DeepSeek
по вашему личному ключу. Вы платите только за то, что использовали.

## Шаг 1. Зарегистрируйтесь

1. Откройте сайт <https://platform.deepseek.com>.
2. Нажмите **Sign up** (регистрация).
3. Введите свою почту и придумайте пароль.
4. Откройте почту, найдите письмо от DeepSeek и введите код из письма на сайте.
5. Готово: вы вошли в личный кабинет.

Можно войти и через Google, если такая кнопка есть.

## Шаг 2. Пополните баланс

Без денег на балансе ключ не работает. Когда баланс станет нулевым,
DeepSeek сразу перестаёт отвечать (ошибка `Insufficient Balance`).

1. В меню слева нажмите **Top up** (пополнить).
2. Выберите сумму. Для начала хватит нескольких долларов.
3. Выберите способ оплаты: банковская карта, PayPal, Alipay или WeChat Pay.
   Набор способов зависит от страны аккаунта.
4. Оплатите и проверьте, что сумма появилась на балансе.

Важно: карты российских банков DeepSeek обычно не принимает.
Нужна карта иностранного банка или PayPal.

## Шаг 3. Создайте API-ключ

Ключ — это длинный пароль, по которому DeepSeek узнаёт, что запрос от вас.

1. В меню слева нажмите **API keys**.
2. Нажмите **Create new API key**.
3. Введите имя ключа, например `python-agent`.
4. Скопируйте ключ (он начинается с `sk-`).

Ключ показывают только один раз. Если не скопировали — удалите его
и создайте новый.

Никому не показывайте ключ: не отправляйте его в чат, не вставляйте
в YAML и не коммитьте в git. Кто знает ключ, тот тратит ваши деньги.

## Шаг 4. Положите ключ в `.env`

1. Откройте файл `.env` в корне проекта. Если файла нет — создайте его.
2. Добавьте строку (вместо `sk-...` вставьте свой ключ):

```dotenv
DEEPSEEK_API_KEY=sk-...
```

3. Сохраните файл. Остальные строки в `.env` не трогайте.

## Шаг 5. Добавьте DeepSeek в `config/models.yaml`

Добавьте `deepseek` в существующие разделы `providers` и `models`.
Не заменяйте текущую конфигурацию и не создавайте повторные разделы.

```yaml
providers:
  deepseek:
    kind: openai
    base_url: https://api.deepseek.com
    api_key_env: DEEPSEEK_API_KEY

models:
  deepseek:
    provider: deepseek
    model: deepseek-flash
    context_window: 256000
    max_tokens: 16000
    # Тариф Flash в часы пик без кеша, USD за 1M токенов (самый дорогой вариант).
    pricing: {input_per_mtok: 0.3, output_per_mtok: 1.2}
    reasoning:
      supported: true
      allowed_efforts: [none, low, high, max]
      default_effort: high
      wire_parameter: reasoning_effort
      history: current_turn
```

- `deepseek-flash` — быстрая и дешёвая модель. Для сложных задач можно
  указать `deepseek-v4-pro`, но она дороже.
- `256000` — лимит контекста в приложении. Сама модель держит до 1M токенов,
  но большой контекст стоит дороже.
- `pricing` нужна, чтобы агент считал расходы и соблюдал денежный лимит сессии.
- `none` в `reasoning_effort` выключает рассуждения, `low`/`high`/`max`
  включают их с разной силой.

## Шаг 6. Проверьте и запустите

Из корня проекта выполните:

```bash
# Проверяет конфигурацию и наличие ключа, но не делает запрос к DeepSeek.
uv run pyagent config check --strict
```

Если ошибок нет:

1. Перезапустите агент.
2. При создании новой сессии выберите модель `deepseek`.
3. Напишите «привет». Если агент ответил — всё работает.

Если в UI сохранены переопределения моделей или провайдеров, они приоритетнее YAML.
При необходимости нажмите «Сбросить к файлу» для нужного элемента.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| `401` или `Authentication Fails` | Ключ неверный. Проверьте строку в `.env`, создайте новый ключ |
| `402` или `Insufficient Balance` | Закончились деньги. Пополните баланс (шаг 2) |
| `429` | Слишком много запросов. Подождите минуту |
| Модель `deepseek` нет в списке | Проверьте YAML (шаг 5) и перезапустите агент |
| `config check` пишет `Legacy LLM structure variables` или `AGENT_DEFAULT_LLM_PROFILE names no model` | В `.env` остались старые строки. Удалите их командой ниже |

Команда удаляет из `.env` старые строки `AGENT_LLM_*` и `AGENT_DEFAULT_LLM_PROFILE`
(для macOS; ключи `AGENT_LLM_API_KEY` и `DEEPSEEK_API_KEY` она не трогает):

```bash
sed -i '' -E '/^(AGENT_LLM_(BASE_URL|MODEL|TIMEOUT_SECONDS|MAX_RETRIES|MAX_TOKENS|PROFILES)|AGENT_DEFAULT_LLM_PROFILE)=/d' .env
```

Если ключ показали кому-то (в чате, на скриншоте), удалите его в кабинете
в разделе **API keys** и создайте новый.

Баланс и расходы видны в кабинете на <https://platform.deepseek.com>.
