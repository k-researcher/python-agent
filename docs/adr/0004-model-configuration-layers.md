# ADR 0004: Два слоя конфигурации моделей

English version: [0004-model-configuration-layers.en.md](0004-model-configuration-layers.en.md).

## Статус

Принято. Заменяет JSON-строку `AGENT_LLM_PROFILES` в `.env`.

## Контекст

Прежняя конфигурация хранила все профили моделей в одной JSON-строке в `.env`. Строка
смешивала секреты и структуру. Её было трудно редактировать и проверять. Одна
синтаксическая ошибка останавливала запуск. Все модели использовали одно окно контекста.
Пользователю также нужен интерфейс для подключения провайдеров и моделей.

## Решение

Итоговая конфигурация состоит из двух слоёв:

1. **Базовый слой:** `config/models.yaml`. Файл описывает провайдеров, модели и
   маршрутизацию. Файл не содержит ключей. Провайдер ссылается на переменную окружения через
   `api_key_env`. Если файла нет, runtime использует прежние переменные `AGENT_LLM_*`.
2. **Слой интерфейса:** переопределения в базе данных. Их изменяет `/api/settings/models`.
   - Переопределение заменяет отдельные поля элемента из YAML. Остальные поля остаются из
     YAML.
   - Переопределение может отключить элемент из YAML. Файл YAML не изменяется.
   - Переопределение может добавить провайдера или модель, которых нет в YAML.
   - «Сбросить к файлу» удаляет переопределение.
   - Интерфейс может хранить API-ключ. Сервер шифрует ключ через Fernet. Мастер-ключ —
     `AGENT_SECRET_KEY`. В embedded-режиме, если переменная не задана, сервер создаёт
     `data/secret.key` с правами 0600.

Представление для интерфейса показывает источник каждого поля: файл, интерфейс, окружение
или прежние переменные. API никогда не возвращает ключ. API возвращает только `api_key_set`
и последние четыре символа.

Схема поддерживает такие типы транспорта:

- `openai`: OpenAI-совместимый `/chat/completions` (шлюзы, GLM, LM Studio, MLX, Ollama).
- `openai_responses`: OpenAI Responses API (Codex и reasoning-модели GPT).
- `anthropic`: Anthropic Messages API (Claude).
- `jev`: модели решений TypeSafe.

Каждая модель имеет своё окно контекста, свой лимит ответа и свои допустимые уровни
рассуждений. Runtime выбирает модель в таком порядке: явная модель, модель роли, модель по
умолчанию.

## Последствия

- Экземпляры API и workers читают одинаковые переопределения из базы данных. Смонтированный
  файл YAML должен быть одинаковым на всех хостах.
- Провайдер без ключа не останавливает запуск. Интерфейс показывает его как «не настроен».
- Недопустимое переопределение даёт HTTP 422. Сервер его не сохраняет.
- `agent config check --strict` проверяет файл YAML без базы данных.
- Адаптеры `anthropic` и `openai_responses` появятся позже. До этого маршрутизация на эти
  типы отклоняется.
