# ADR 0001: Самостоятельный Python runtime

English version: [0001-runtime.en.md](0001-runtime.en.md).

## Статус

Принято.

## Контекст

Агент должен работать на одной рабочей станции и запускаться одной командой. Агент должен
сохранять состояние сессий после перезапуска. Агент должен останавливать каждый побочный
эффект до подтверждения пользователя.

## Решение

Используем FastAPI, asyncio и SQLite в одном локальном процессе. HTTP и WebSocket работают на
одном порту. Состояние сессий хранится в базе данных. Состояние не хранится в памяти или в
JSON-файлах.

## Причины

- Одна команда запуска на всех операционных системах.
- Атомарные изменения состояния сессий.
- Восстановление после перезапуска.
- Нет собственной реализации WebSocket.
- Одна центральная точка контроля подтверждений.

## Последствия

Runtime имеет ограниченный локальный контекст, дочерние сессии, флаги возможностей,
подтверждения и аудит исходящих данных. SQLite — база данных по умолчанию. PostgreSQL также
разрешён через асинхронный драйвер.

Однопроцессный режим остаётся для локальной работы. ADR 0002 описывает горизонтальное
масштабирование: PostgreSQL, Redis Streams, Pub/Sub и отдельные workers.
