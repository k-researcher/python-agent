# Подключение GigaChat от Сбера

Мини-инструкция для python-agent. Общие настройки описаны в [README](../README.md).

## 1. Добавьте ключ в `.env`

В корне проекта добавьте переменную, сохранив остальные настройки:

```dotenv
GIGACHAT_AUTH_KEY=ключ_авторизации_из_кабинета
```

Нужен **ключ авторизации**, а не временный access token. Префикс `Basic `
добавлять не нужно: приложение добавляет его само. Не отправляйте ключ в чат,
не помещайте его в YAML и не коммитьте `.env`.

## 2. Дополните `config/models.yaml`

Добавьте `sber` в существующие разделы `providers` и `models`.
Не заменяйте текущую конфигурацию и не создавайте повторные разделы YAML.

```yaml
providers:
  sber:
    kind: openai
    base_url: https://api.giga.chat/v1
    dialect: functions
    auth:
      type: oauth_client_credentials
      token_url: https://ngw.devices.sberbank.ru:9443/api/v2/oauth
      key_env: GIGACHAT_AUTH_KEY
      scope: GIGACHAT_API_PERS

models:
  sber:
    provider: sber
    model: GigaChat
    context_window: 8192
    max_tokens: 2048
    reasoning: {supported: false}
```

- `GIGACHAT_API_PERS` — scope для физических лиц. Для корпоративного подключения
  используйте scope своего договора.
- `8192` — консервативный лимит контекста приложения в этом примере,
  а не утверждение о максимальном окне модели.
- Ключ `sber` — локальное имя провайдера и модели; `GigaChat` — имя модели API.

## 3. Проверьте конфигурацию

Из корня проекта выполните:

```bash
# Проверяет конфигурацию и наличие ключей, но не делает тестовый запрос к Сберу.
uv run pyagent config check --strict
```

После проверки перезапустите свой экземпляр приложения и выберите модель `sber`
при создании новой сессии. Менять модель по умолчанию необязательно.

Если в UI сохранены переопределения моделей или провайдеров, они приоритетнее YAML.
При необходимости используйте «Сбросить к файлу» для соответствующего элемента.

## Границы проверки

Инструкция составлена 18 октября 2026 года по официальной документации GigaChat.
С 17 июля 2026 года новые подключения используют адрес `https://api.giga.chat`.
Токен по-прежнему выдаёт `ngw.devices.sberbank.ru:9443`. Живой запрос к Сберу
по этой инструкции не проверялся.
